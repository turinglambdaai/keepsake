Keepsake

file-level backup · zero decryption

A time machine for your desktop WeChat data.

WeChat keeps no server-side copy of your chats — your local data folder is the only one that exists. Keepsake snapshots it the way macOS snapshots your disk: deduplicated, versioned, restorable. It handles files, never content.

View on GitHub How it works

Where is my data, how big?

Keepsake finds every WeChat account directory on the machine and shows what each holds — message databases, images, videos, files — with real sizes.

When was it backed up, to where?

Every snapshot lands on a per-device timeline: when, how big, what changed, and which volume it lives on. No black box, ever.

How do I get it back?

Pick a snapshot, restore it in place — after an automatic safety snapshot of the current data. Verify by opening WeChat itself.

Design principles

Zero decryption

No key extraction, no database decryption, no process injection — the line Keepsake never crosses. Viewing and restoring happen through WeChat itself.

Escapable format

A repository is a plain directory of JSON manifests and content-addressed blobs. If Keepsake vanished tomorrow, jq and cp can rebuild any snapshot.

The hub is never a single point

Agents write the same repository straight to a local volume or NAS mount. A self-hosted hub (Docker) adds scheduling, dedup reports, and a multi-device timeline — nothing depends on it staying up.

Restore never destroys

Every restore begins with an automatic safety snapshot of the current data. Paying is never what keeps your backups alive.

Platforms

macOS Windows Linux iOS / Android → via WeChat's own migrate flow

Desktop clients keep data in local files — that is Keepsake's whole world. Phones sandbox WeChat beyond reach, so phone history joins the backup through WeChat's built-in migrate-to-desktop step, then gets snapshotted like everything else.
