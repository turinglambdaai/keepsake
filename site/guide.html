🚀五分钟上手

下载、打开、拍第一份快照。教程到这里就结束了——本页其余内容都是可选的。

  1. 安装。到 Releases 页下载 keepsake-0.1.0-macos-arm64.dmg（Apple Silicon）或 keepsake-0.1.0-macos-x64.dmg（Intel）。把 Keepsake 拖进「应用程序」。v0.1.0 未签名公证：首次打开请右键点图标，选「打开」，再点一次「打开」。
  2. 给一次完全磁盘访问。微信把数据存在受保护目录里，首次快照时 macOS 会弹窗。到「系统设置 → 隐私与安全性 → 完全磁盘访问权限」勾选 Keepsake，重启应用。放心：Keepsake 对微信目录只读，写入只发生在备份仓库。
  3. 拍第一份快照。左侧选中一个微信账号，点「Snapshot Now」。第一次是全量入库，会慢；之后每次近乎瞬时。
  4. 浏览时间线。每份快照一行：何时、多少文件、多大。按设备分列，永远是一笔明账。
  5. 做一次恢复演练。选一份旧快照，点「Restore」，确认。恢复开始前，Keepsake 自动先给当前数据拍一份保险快照。恢复完，打开微信本体验收。真出事的那天，你已经练过一遍。

偏好命令行？引擎同款能力在 racket app/cli.rkt：discover / snapshot / status / restore。

📸快照与自动快照

点「Snapshot Now」随手拍一份。想无人值守：把「Auto snapshot」拨到每 15 分钟、每小时、每 6 小时或每天，默认关闭。调度判断是纯函数，逐条测试覆盖。

🧬去重

仓库按内容寻址：媒体按整个文件去重，消息库（SQLite）按页去重，页大小从文件头读取。第一个快照是全量，之后每份只新增变化过的块——用几年也不会翻倍占盘。

🕘时间线浏览

左侧选账号，右侧是它的全部快照。每行写明何时、多少文件、总大小。任意一行都可以恢复；没有任何黑箱。

✅校验

怀疑备份坏了？跑一次 verify：逐份审计 manifest，重新哈希每一个被引用的 blob，坏一块报一块，报到名字。仓库是纯目录，校验不依赖 hub 活着，也不依赖 Keepsake 本体。

↩️恢复

选快照，点「Restore」，确认。执行分两阶段：先逐一预检所有 blob，再碰你的目录；写完再核对每个文件的大小。权限与修改时间一并还原。恢复永远以保险快照开场——不会越恢复越糟。

⚠️ 恢复会覆盖同路径文件
恢复把选定快照原位铺回账号目录。动手前的保险快照保住现状；对结果不满意，就恢复那份保险快照。

🧹空间回收

删旧快照不会立刻腾出空间——还被引用的块永远保留。GC 工具清走超过宽限期的无引用块；宽限期保护正在写入的快照，绝不误删在途数据。

🛰️自托管 Hub

是什么

仓库目录上的一层 HTTP 门面：多台电脑把快照推进同一个仓库，浏览器打开就能看所有设备的时间线和仓库大小。带令牌认证，路径穿越一律拒绝。格式与本地卷完全相同——hub 不是另一种存储。

谁需要

一台电脑用不到它：直接写本地盘或 NAS 挂载即可。有两台以上机器、想把备份集中到家庭服务器的人，才需要 hub。它永远不是单点——agent 随时可以退回目录直写。

Docker 一句话

docker build -t keepsake-hub hub/ docker run -d -p 8080:8080 -p 8081:8081 \ -v /mnt/user/keepsake:/data \ -e KEEPSAKE_HUB_TOKEN=change-me keepsake-hub

试用与激活

hub 按 MT Photos 式的诚实方案计费：自仓库创建日起 30 天全功能试用，KS1 激活令牌离线验证。过期后拒绝新写入（HTTP 402），读取与恢复永远免费——数据不会被扣住，agent 会自动改走目录直写。

🚧 诚实标注（v0.1.0）
官方签名 Docker 镜像尚未发布（M2 里程碑）。上面的镜像需要你从源码构建；安装器签名与公证同样在 M2。

❓常见问题

我的聊天记录会被解密吗？
不会。Keepsake 不提取密钥、不解密数据库、不注入微信进程。它只复制文件，像 Time Machine 复制磁盘那样。查看与搜索记录，都打开微信本体。这条线写进产品定义，永不跨越。
数据存在哪？
默认在 ~/KeepsakeBackup，应用内可以改到任何位置：外置硬盘、NAS（SMB 挂载）或自托管 hub。仓库是明文目录——JSON manifest 加按 SHA-256 命名的 blob。就算 Keepsake 明天消失，jq 和 cp 也能拼回任何一份快照。
要注册账号吗？有联网吗？
不用账号，默认不联网。快照落在你指定的本地卷；只有你主动启用自托管 hub 时，数据才流向你自己的服务器。没有遥测，没有云端。
支持 Windows / Linux 吗？
v0.1.0 是 macOS 首发（14.0+，Apple Silicon 与 Intel）。Windows 与 Linux 排在 M2。手机端被平台沙盒锁住：手机历史先用微信自带的「迁移到电脑」进入桌面端，之后照常快照。
怎么更新？
手动。v0.1.0 没有自动更新器：到 Releases 页下载新 dmg，覆盖安装。仓库格式向前兼容，旧备份照常打开。
怎么卸载？
退出应用，把「应用程序」里的 Keepsake 拖进废纸篓。想连备份一起删：先确认不再需要，再删掉仓库目录（默认 ~/KeepsakeBackup）。那是你唯一的多版本副本，删之前想两次。
